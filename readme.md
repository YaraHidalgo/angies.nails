Este proyecto consiste en el desarrollo de una página web de servicios de uñas, creada como parte de un curso de Front-End. La página utiliza HTML semántico para organizar el contenido en secciones como encabezado, navegación, contenido principal y pie de página. También incorpora CSS para mejorar el diseño visual, los colores, la tipografía y la distribución de los elementos, logrando una presentación más atractiva y ordenada.
El objetivo es aplicar los conocimientos básicos de HTML y CSS para presentar los servicios de manicura y cuidado de uñas. Además, el proyecto está conectado con GitHub para gestionar y mantener un registro de los cambios realizados en el código. En futuras etapas, se podrá incorporar JavaScript para agregar interactividad y mejorar la experiencia del usuario.
